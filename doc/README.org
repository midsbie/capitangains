* Overview

This directory holds the official Interactive Brokers (IBKR) reporting guide, which contains the authoritative specifications for IBKR reports and statements.

* Files

- =IBKR-reporting_guide.pdf= :: The original IBKR reporting guide containing the official reporting/statement document specifications.

- =IBKR-reporting_guide.txt= :: A textual version derived from the PDF, produced by running:

  #+begin_src sh
  pdftotext -layout ./doc/IBKR-reporting_guide.pdf ./doc/IBKR-reporting_guide.txt
  #+end_src
